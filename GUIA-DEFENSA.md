# Guía breve para explicar el código

1. **HTML:** cada archivo es una página. `header` contiene el nombre y menú; `main`, la información; `footer`, el pie.
2. **Navegación:** los enlaces `a` abren las otras páginas. El menú se acomoda en varias filas en el celular.
3. **Listas:** `ul` muestra elementos sin orden; `ol` muestra la organización con números.
4. **Tabla:** `tr` crea filas; `th`, encabezados; `td`, datos de matrícula y mensualidad.
5. **Imágenes:** `img` usa `src` para indicar el archivo y `alt` para describirlo. Las fotos están pendientes.
6. **Multimedia:** `video` y `audio` tienen controles de reproducción. `track` incluye subtítulos.
7. **CSS:** define colores café y mostaza, bordes y espacios. Grid organiza columnas y `@media` adapta el contenido al celular.
8. **Efectos:** `transition` cambia suavemente los colores y la opacidad. Al pulsar un enlace, JavaScript agrega la clase `saliendo` y espera 180 milisegundos con `setTimeout` antes de abrir la página. `@keyframes` hace aparecer el contenido. El evento `pageshow` restaura la visibilidad al volver con Atrás.
9. **JavaScript:** `querySelector` busca elementos. `addEventListener` responde a eventos. El selector de categoría usa `change`; `forEach` recorre las actividades y `hidden` oculta las que no corresponden.
10. **Formulario:** `required` y `type="email"` validan los campos. `preventDefault()` evita el envío normal. `FormData` recoge los datos y `mailto:` prepara el mensaje. El visitante debe enviarlo desde su aplicación de correo.

El correo real sigue pendiente. No se guardan mensajes. Practica cambiando un texto, un color y una categoría para entender cómo funciona cada parte.
